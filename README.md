# 对象存储推荐：按用途选方案，图床、备份和静态资源分发的账单逻辑一次讲清

搜"对象存储推荐"的人，处境其实差得很远。

有人只是想把博客图片从服务器硬盘里搬出去，有人要长期备份几百 GB 的照片和录像，还有人手上是个每天被下载几百 GB 的资源站。这三种需求，正确的答案基本不重叠——所以任何一份不看用途就直接给结论的推荐，都可以先放一边。

下面按"你实际在为什么付钱"这个角度来拆，最后落到具体的套餐和价格上。

## 先分清用途，看的指标完全不一样

对象存储（Object Storage）本质就是"通过网络用 API 存取文件的桶"，S3 是这套接口事实上的标准，所以绝大多数工具都能互通。但不同用途，账单里最贵的那个数字不一样。

**做图床、博客附件、小文件外链。** 存储总量通常几个 GB 到几十 GB，单个文件小、请求次数多、读取频繁。要盯的是：有没有免费额度、请求次数是否单独计费、有没有能直接用的默认域名（省掉备案）、有没有防盗链。

**做备份和归档。** 存储量大，读的次数可能一年就几次。要盯的是存储单价，以及那些藏在细则里的条件——最短存储期、提前删除费。有些服务商单价看着低，但你删文件的时候会发现还在扣钱。

**做静态资源站、媒体分发、软件下载。** 存储量中等，下行流量可能是 TB 级。这一类的费用大头几乎永远在下载流量上，选之前先把下行单价乘以你的月流量算一遍，比看任何评测都管用。

绝大多数人出事，都出在第三类。

## 判断价格只看四个数字

不管选哪家，把这四项摆出来，结论基本就出来了：

1. **存储单价**：每 GB 每月多少钱
2. **下行流量单价**：每 GB 多少钱——通常是最容易被低估的一项
3. **请求次数是否计费**：GET / PUT 每千次多少钱，小文件多的场景会很难看
4. **隐性条件**：最短存储期、提前删除费、跨区域复制的附加费用

举个直观的对照：AWS S3 标准存储公开价约 $0.023/GB/月，但从 S3 把数据传到公网要收约 $0.09/GB；Cloudflare R2 的存储约 $0.015/GB/月，出站流量是 $0。同样每月 10TB 出站，一边差不多 900 美元，另一边是 0。反过来，如果你的数据几乎只写不读，S3 的归档层能压到 $0.00099/GB/月，这种深度归档 R2 并没有对应产品。

国内大厂云的公开定价，阿里云 OSS 标准存储大约在 ¥0.12/GB/月这个量级，同样按存储、流量、请求三项叠加计费。

所以"哪家便宜"这句话本身没有意义，要看你的读写比例长什么样。

## 目前大致是三条路线

| 路线 | 代表 | 价格特征 | 更适合谁 |
| --- | --- | --- | --- |
| 国内大厂云 | 阿里云 OSS、腾讯云 COS | 标准存储约 ¥0.12/GB/月量级，存储+流量+请求分别计费 | 需要合规资质、生态集成、功能最全的企业业务 |
| 海外 S3 兼容 | Cloudflare R2、Backblaze B2、AWS S3 | R2 存储约 $0.015/GB/月、出站免费；B2 有 10GB 免费存储+每天 1GB 免费出站；S3 出站约 $0.09/GB | 用户主要在海外、或者对接的是海外工具链 |
| 国内性价比服务商 | 雨云 ROS 等 | 套餐制，按月包存储+流量，单价明显低于大厂 | 个人开发者、站长、备份与小规模分发 |

海外服务商的公开价格会随汇率和调价浮动，上面这些数字按各家官网公开定价整理，实际下单前值得再核一次。

第三条路线值得单独说一句：它不是大厂云的"平替"，而是把按量账单换成了月租账单。好处是费用可预测，坏处是配额是死的——买多了浪费，买少了要么升级要么被限速。

## 雨云对象存储：只对两件事收钱

雨云（RainYun）的 ROS 属于第三条路线，它的计费逻辑简单到有点反常：**只有两个计费项——存储空间，和从存储桶下载出去的流量。**

具体说：

- 你上传文件到对象存储，不扣流量
- 从存储桶下载 1GB 文件，扣 1GB 流量
- HTTPS 请求次数、GET/PUT 操作类型这些在别家会单独列项的东西，这里不计费
- 存储桶所在区域的云服务器用内网地址访问同区域对象存储，上传下载都不计流量——连按流量计费的云服务器那一侧也不计
- 默认提供可直接访问的域名，不做图床测试不需要先去备案；要绑自己的域名也支持，并且兼容 SSL 证书中心，能同步自动更新证书
- 协议上支持 S3、FTP、SFTP，兼容 PathStyle 和 VirtualHost 两种访问方式，PicGo、rclone、Alist、S3Browser 这类现成工具都能直接接

对图床和附件这类场景，前两条意味着你只对"别人看了多少"付费，不对"自己传了多少"付费。对备份场景，这个优势就用不上了，因为备份几乎只写不读。

### 两个节点的定位完全不同

雨云的对象存储分了两个区域，方向是反的，选错会白花钱：

**浙江宁波**——SSD 作为存储底层，带宽规格高，定位是资源加速和分发，只提供**流量优先套餐**（存储配额小、流量配额大）。

**湖北十堰**——定位超大容量，适合资源归档和备份，提供**存储优先套餐**和**平衡套餐**。

一句话概括：图片、视频、前端静态资源走宁波；长期归档、冷数据、备份走十堰。买之前先想清楚你的数据是"要被人频繁下载"还是"躺在那里不动"。

### 套餐外怎么算，以及那道保险丝

套餐用完之后的默认行为是停止访问，不会自动继续扣钱。想继续用，需要在控制台手动开启弹性计费，超出部分按区域标准计费：

| 区域 | 套餐外存储 | 套餐外流量 |
| --- | --- | --- |
| 浙江宁波 | 0.5 元/GB/月 | 0.1 元/GB |
| 湖北十堰 | 0.2 元/GB/月 | 0.2 元/GB |

弹性计费可以随时关掉，用量耗尽后上传或下载功能会在几分钟内自动停掉。官网套餐页面上标注的套餐内单价大约是流量每 GB 0.05 元/月、存储每 GB 0.2 元/月，也就是说流量这一项，套内和套外的价差是明显的。

顺带说几个购买时容易被忽略的官方条件：雨云产品提供七天无理由退订；购买后可以获得 10% 以上的积分返利，积分能直接提现或兑换优惠券。积分返利这一点对长期续费的人有点用，相当于变相打了个折。

另外雨云长期有 10GB 存储 + 10GB 流量的免费额度领取渠道，通常是在积分商城用积分兑换，每个实名账号的情况以控制台实际显示为准。想先试再买的人可以走这条路。

## 这些档位分别适合谁

**10 元档（10GB 存储 + 50GB 流量，宁波）** 是整个列表的入门线。个人站长的博客配图、几个小程序的图标资源，基本够用。它最大的价值是让你把整套流程（建桶、配域名、接 PicGo 或 WordPress 插件）跑通一次，成本 10 块钱。

**15 元这一档有两个选项，方向完全相反。** 十堰的 50GB 存储 + 50GB 流量适合"存得多、看得少"；宁波的 20GB 存储 + 100GB 流量适合"存得少、看得多"。同价位下，十堰多给你 30GB 存储，宁波多给你 50GB 流量。选哪个取决于你更怕哪一项先爆。

**20 元档也有一组对照值得看。** 十堰的 100GB + 100GB 和宁波的 20GB + 100GB 同价，差的是 80GB 存储。如果你的图片总量会稳步增长，十堰这一档的性价比明显更好；但如果访问者集中在华东、你更在意加载速度，宁波的 SSD 底层和带宽就是花钱买的东西。

**99 元 / 100 元这一段是分水岭。** 十堰 1TB 存储 + 250GB 流量适合正在做影像归档或者长期备份的人；宁波 200GB 存储 + 1TB 流量适合已经有一定访问量、每月下载量稳定在几百 GB 的资源类站点。

## 常见问题

**超过套餐会把卡刷爆吗？**

不会。弹性计费默认是关闭的，用量耗尽后服务停止访问，不会自动扣费。需要继续用才手动打开，而且可以随时关掉，用完自动停。这是它和纯按量计费最本质的区别。

**上传文件要另外收费吗？**

不收费。只有从存储桶往外下载才计流量，上传不计。

**一定要自己有备案域名吗？**

不一定要。雨云给对象存储配了可直接使用的默认域名，测试和内部使用不需要额外备案。要绑自己的域名也可以，并且能对接 SSL 证书中心自动续证。

**能在上面跑 WordPress 附件、PicGo 图床、Alist 这类东西吗？**

可以，因为它兼容 S3 协议，也支持 FTP 和 SFTP。PicGo + Typora、WordPress 的远程附件插件、rclone 同步、Alist 挂载，这些都是现成可用的组合。

**将来容量不够了怎么办？**

可以在控制台弹性变更套餐，升级按差价补，也支持降级。不用重新买一套。

**退订麻烦吗？**

官方写明雨云产品提供七天无理由退订，期间可以自助操作。所以不确定档位的时候，先买小一档试一周，比在评测里反复纠结划算。

## 最后一句判断

对象存储推荐这件事没有唯一答案，但有唯一正确的判断顺序：先算清楚你的存储量和月下载量，再看每家的存储单价和下行单价，最后才比较功能和生态。

如果按这个顺序算下来，你每个月的下载量在几十 GB 到几 TB 之间、又不想为请求次数和复杂计费项操心，那套餐制确实比按量计费好算账——雨云这类国内性价比服务商的套餐就是为这种场景准备的。反过来，如果你的数据基本只写不读，或者需要合规资质与全球节点覆盖，那还是回到大厂云和海外 S3 兼容服务那边去比，套餐制帮不上忙。
